# FuelVideo — копирование видео и звука из СВН «Интеллект» по данным из Excel

## 1. Назначение

Программа запускается локально на АЗС (на той машине, где доступны диски с видеоархивом
этой АЗС). Она читает xlsx со списком заправок и для каждой строки копирует видео- и
аудиофайлы нужных камер за интервал вокруг времени заправки.

Результат складывается в отдельный каталог **с сохранением структуры исходного каталога**
(«зеркало источника»).

Основные возможности:

* автоматическое обнаружение каталогов `X:\VIDEO` на всех локальных дисках;
* привязка «ТРК → список камер» в `azs.ini` (одна ТРК может сниматься несколькими камерами);
* интервал копирования настраивается в минутах относительно времени заправки;
* режим «Сканировать» (только поиск, без копирования) и «Копировать»;
* повторный запуск по тому же xlsx безопасен: существующие файлы не перезаписываются;
* CSV-отчёт по файлам и сводка по строкам xlsx;
* лог `logs/app_YYYYMMDD.log` рядом с exe.

## 2. Установка и первый запуск

1. Установите Python 3.8+ (для Windows 7 — строго 3.8.10).
2. Установите зависимости:

   ```bat
   python -m pip install -r requirements.txt
   ```

3. Запустите программу:

   ```bat
   python main.py
   ```

4. При первом запуске рядом с программой (рядом с exe, если это собранный exe) создаются:
   * `settings.ini` — общие настройки и параметры поиска;
   * `azs.ini` — секции АЗС;
   * каталог `logs\`.

5. Откройте `azs.ini` и опишите свою АЗС (секция `[AZS_<номер>]` + `trk_N=камеры`).
6. Выбор АЗС при старте:
   * `current_azs=<число>` — работаем сразу с указанной АЗС, диалог не показывается;
   * `current_azs=auto` — если в `azs.ini` одна секция, она выбирается без диалога;
     если секций несколько, появляется модальный диалог выбора **до главного окна**.

В главном окне текущую АЗС можно сменить кнопкой «Сменить АЗС» (доступна всегда).

## 3. Настройка settings.ini

### Секция `[general]`

| Параметр | Описание |
|---|---|
| `current_azs` | `auto` либо номер АЗС (`75`). См. раздел 2. |
| `output_root` | Куда копировать, если в секции АЗС не задан свой `output_root`. |
| `minutes_before` | Сколько минут **до** времени заправки копировать (целое, `>= 0`). |
| `minutes_after` | Сколько минут **после** времени заправки копировать (целое, `>= 0`; больше 120 — предупреждение в лог). |
| `copy_mode` | `copy` — копировать (по умолчанию), `move` — переносить (исходник удаляется после успешного копирования). |
| `threads` | Потоков копирования, `>= 1`. `1` — последовательно. |
| `video_roots` | `auto` — искать `X:\VIDEO` на всех дисках; либо явные пути через `;`: `D:\VIDEO;E:\VIDEO`. |
| `video_root_subdir` | Имя подкаталога с видео на диске (по умолчанию `VIDEO`). |
| `include_audio` | `true` — копировать и звук (`.wNN`), `false` — только видео. |

### Секция `[finder]`

| Параметр | Описание |
|---|---|
| `path_date_regex` | Регулярное выражение имени час-каталога. Обязательны именованные группы `(?P<d>)`, `(?P<m>)`, `(?P<y>)`, `(?P<H>)`. По умолчанию `(?P<d>\d{2})-(?P<m>\d{2})-(?P<y>\d{2})\s+(?P<H>\d{2})` — то есть `12-10-26 10`. |
| `path_date_filter` | `true` — не открывать час-каталоги, не пересекающиеся с интервалом. |
| `path_date_margin_hours` | Запас в часах при отборе час-каталогов (страховка для файлов на границе часа). |
| `time_source` | `mtime` (время изменения) или `ctime` (время создания). |
| `video_suffix_video` | Суффикс видеофайлов, `NN` — номер камеры. По умолчанию `._NN`. |
| `video_suffix_audio` | Суффикс аудиофайлов. По умолчанию `.wNN`. |
| `segment_duration_sec` | Длительность одного файла-сегмента, сек. `0` — неизвестна (тогда используется окно `start-5 мин .. end+5 мин`). |
| `mtime_fix_sec` | Поправка к времени файла, сек. Может быть отрицательной. |
| `skip_dirs` | Служебные каталоги первого уровня, которые нельзя обходить: `META,PROTECTED,INDEX_DATA`. |

Если параметра нет в ini — программа выдаёт понятную ошибку (никаких «тихих» дефолтов в коде;
дефолты есть только в шаблоне, который создаётся при первом запуске).

## 4. Настройка azs.ini

Одна секция = одна АЗС, имя строго `[AZS_<номер>]`.

```ini
[AZS_75]
; video_roots не задан -> используется [general].video_roots (auto)
output_root=D:\VideoExport\AZS75
trk_1=07,08
trk_2=09
trk_3=10,11
trk_4=12
trk_5=13
trk_6=14
```

| Параметр | Описание |
|---|---|
| `video_roots` | Необязательный. Переопределяет общий: `D:\VIDEO;E:\VIDEO`. |
| `output_root` | Необязательный. Если не задан — `<[general].output_root>\AZS<номер>`. |
| `trk_N` | Список камер `01..99` через запятую для ТРК `N`. Одна ТРК может сниматься несколькими камерами. Номера можно писать без ведущего нуля: `7` → `07`. |

Вторая АЗС — просто ещё одна секция:

```ini
[AZS_76]
video_roots=E:\VIDEO
output_root=D:\VideoExport\AZS76
trk_1=01,02
trk_2=03
```

## 5. Структура входных данных

### xlsx (лист 1, первая строка — заголовки)

| Колонка | Использование |
|---|---|
| `emtcodefrm` | игнорируется |
| `contrcode` | игнорируется |
| `cardcode` | номер карты, только для отчёта |
| `shiftdate` | игнорируется |
| `docdate` | **точная дата/время заправки** — центр интервала копирования |
| `azscode` | номер АЗС (например 75) |
| `realdose` | литры: читается, но **ни на что не влияет** |
| `trk` | номер ТРК (1..6 и т.п.) |

Поддерживаются даты типа `datetime` из Excel, строки `ДД.ММ.ГГГГ ЧЧ:ММ(:СС)` и
`ГГГГ-ММ-ДД ЧЧ:ММ(:СС)`, а также числовые серийные номера дат Excel.

### Каталог VIDEO на диске

```
g:\VIDEO\13-10-26 01
g:\VIDEO\12-10-26 22
g:\VIDEO\12-10-26 20
g:\VIDEO\12-10-26 10
g:\VIDEO\11-10-26 21
g:\VIDEO\META
g:\VIDEO\PROTECTED
g:\VIDEO\INDEX_DATA\
```

Правила:

* каталоги первого уровня: `DD-MM-YY HH` (год двузначный: `26` → 2026), час `00..23`;
* каталоги за час создаются только там, где есть запись — пропуски нормальны;
* файлы лежат **прямо** в час-каталоге, без вложенных подкаталогов;
* `META`, `PROTECTED`, `INDEX_DATA` — служебные, не обходятся;
* видео: `<произвольное_имя>._NN`, звук: `<произвольное_имя>.wNN` (`NN` — камера `01..99`);
  камера и тип определяются **только по суффиксу расширения**, имя файла произвольное;
* видео и звук могут лежать на разных дисках у разных АЗС.

## 6. Структура выходных каталогов (зеркало источника)

```
g:\VIDEO\12-10-26 10\A._07   ->   D:\VideoExport\AZS75\12-10-26 10\A._07
```

* относительный путь файла от `video_root` повторяется один-в-один;
* никаких `{azs}`, `{date}`, `{cardcode}` в пути нет;
* копируются только файлы, прошедшие фильтр по интервалу и суффиксу, а не весь час-каталог;
* существующий файл того же размера пропускается (`already_exists`);
* существующий файл другого размера перезаписывается (`size_mismatch_overwritten`, warning в лог);
* в режиме `move` исходник удаляется только после успешного копирования.

Рядом с результатом пишутся два CSV-отчёта:

* `report_<дата>_<время>.csv` — по файлам: `azs;docdate;trk;camera;kind;src;dst;status;error`;
* `report_<дата>_<время>_summary.csv` — сводка по строкам xlsx: найдено/скопировано/уже было/не найдено.

Статусы: `copied`, `already_exists`, `size_mismatch_overwritten`, `not_found`, `error`
(плюс служебные `found`, `pending`, `skipped_other_azs`, `stopped`).

## 7. Как изменить интервал копирования

```
start = docdate - minutes_before
end   = docdate + minutes_after
```

Правьте `[general].minutes_before` и `[general].minutes_after` в `settings.ini`.
Например, `minutes_before=2`, `minutes_after=10` — копируется интервал от 2 минут до
до заправки до 10 минут после. Литры (`realdose`) на интервал не влияют.

Файл попадает в результат, если его сегмент `[mtime; mtime + segment_duration_sec]`
пересекается с `[start; end]`. Если длительность сегмента неизвестна
(`segment_duration_sec=0`), используется окно `[start - 5 мин; end + 5 мин]`.

## 8. Как настроить под свою структуру VIDEO

1. Имя час-каталога отличается от `DD-MM-YY HH`? Поправьте `[finder].path_date_regex`,
   сохранив именованные группы `(?P<d>)`, `(?P<m>)`, `(?P<y>)`, `(?P<H>)`.
   Если шаблон не совпал с именем каталога, каталог всё равно будет обойдён
   (безопасное поведение).
2. Время в имени файла, а `mtime` «уезжает»? Подберите `mtime_fix_sec` (например `-3`)
   или переключите `time_source=ctime`.
3. Другая длительность сегмента? Укажите `segment_duration_sec` (в секундах).
4. Другие служебные каталоги? Допишите их в `skip_dirs`.
5. Суффиксы файлов другие? Измените `video_suffix_video` / `video_suffix_audio`
   (символы `NN` обязательны — это подстановка номера камеры).
6. Каталог с видео называется иначе? Измените `video_root_subdir` или задайте
   `video_roots` явными путями.

## 9. Сборка exe (build.bat)

```bat
build.bat
```

Скрипт создаёт venv, ставит `requirements.txt` и запускает:

```bat
pyinstaller --noconfirm --onefile --windowed --name FuelVideo ^
    --add-data "settings.ini;." --add-data "azs.ini;." ^
    --hidden-import openpyxl ^
    main.py
```

Результат: `dist\FuelVideo.exe`. Рядом с exe при первом запуске будут созданы
`settings.ini`, `azs.ini` и `logs\` (шаблоны встроены в код).

## 10. Запуск на Windows 10/11 и на Windows 7

* Windows 10/11 — Python 3.11/3.12, свежий PyInstaller.
* Windows 7 — **Python 3.8.10** и **PyInstaller 5.13.2**: более новые версии Python и
  PyInstaller на Windows 7 не работают. Соберите exe на Windows 7 (или в окружении
  с Python 3.8.10), иначе exe не запустится.

Развёртывание на другой АЗС: положите рядом с exe свой `settings.ini` и `azs.ini`
с секцией этой АЗС.

## 11. Самотестирование (--selftest)

```bat
python main.py --selftest
python main.py --selftest --xlsx "C:\path\to\report.xlsx"
```

Что делает:

1. читает и валидирует ini;
2. выводит обнаруженные каталоги `X:\VIDEO` и корни видеоархива по каждой секции АЗС;
3. по каждой строке xlsx печатает: АЗС, ТРК, docdate, интервал, список камер,
   количество найденных видео/аудио файлов (без копирования);
4. выводит итог «Обойдено каталогов / отсечено фильтром по дате-часу»;
5. код возврата `0`, если хотя бы одна строка обработана без ошибок, иначе `1`
   (`2` — ошибка настроек).

## 12. Частые проблемы

| Симптом | Что проверить |
|---|---|
| `mtime` не совпадает с реальным временем | Установите `mtime_fix_sec` (например `-3`), либо `time_source=ctime`. Помните, что время файла — это время начала сегмента. |
| Камера не находится | Проверьте `trk_N` в `azs.ini` и суффиксы: `._07` для видео, `.w07` для звука. Номера камер — двузначные (`7` → `07`). |
| Файлы не обнаружены | Убедитесь, что `video_roots` указывает на каталог, где лежат час-каталоги `DD-MM-YY HH`; проверьте `path_date_regex` и `skip_dirs`. Запустите `--selftest`: он печатает примеры найденных путей с mtime. |
| «Не найдено ни одного каталога VIDEO» | Диски с архивом не подключены, либо `video_root_subdir` не `VIDEO`. Нажмите «Пересканировать диски» на вкладке «Настройки». |
| Все строки «пропущено (другая АЗС)» | В xlsx колонка `azscode` не совпадает с выбранной АЗС — смените АЗС или проверьте данные. |
| «нет настройки для ТРК» | В `azs.ini` отсутствует `trk_N` для номера ТРК из строки xlsx. |
| Копирование пропускает файлы | Проверьте `minutes_before`/`minutes_after`, `segment_duration_sec` и `path_date_margin_hours`. |
| Кнопки «Сканировать»/«Копировать» серые | Сработал мягкий предохранитель срока действия: см. раздел 13. Введите код разблокировки или проверьте системные часы. |

## 13. Ограничение срока действия

В сборке есть **мягкий предохранитель** срока действия: после даты окончания
контракта копирование блокируется, но программа по-прежнему запускается и честно
предупреждает пользователя. Это **не криптографическая защита**: любой, кто умеет
читать exe, увидит константы.

### Где задаётся

Обе константы жёстко зашиты в [`license.py`](license.py) (в корне проекта, **не** в
`settings.ini` и **не** в `config.py`):

| Константа | Назначение |
|---|---|
| `EXPIRY_DATE` | дата, до которой (включительно) программа работает без ограничений; сейчас `date(2027, 2, 23)` |
| `UNLOCK_PASSWORD_HASH` | SHA-256 хэш пароля разблокировки (hex, нижний регистр); пустая строка — разблокировка недоступна |

> В текущем состоянии репозитория в `UNLOCK_PASSWORD_HASH` стоит **временный
> отладочный пароль**. Перед передачей сборки заказчику замените его своим
> (см. ниже) и храните пароль вне проекта.

### Как это работает

* до `EXPIRY_DATE` включительно (по 23.02.2027) всё работает как обычно;
* начиная с 24.02.2027 кнопки «Сканировать» и «Копировать» блокируются, в строке
  статуса появляется «Срок действия истёк (до 23.02.2027). Копирование заблокировано.»;
* при этом программа **запускается**, главное окно открывается, вкладка «Настройки»
  полностью доступна, а `--selftest` работает всегда, независимо от даты;
* на вкладке «Задания» рядом с кнопкой «Сменить АЗС» появляется кнопка
  «Ввести код разблокировки»; она активна только когда сработала блокировка;
* разблокировка по паролю действует **до конца сессии**: при следующем запуске
  пароль потребуется снова.

### Как сменить дату и пароль

1. Отредактируйте [`license.py`](license.py): `EXPIRY_DATE` и `UNLOCK_PASSWORD_HASH`.
2. Пересоберите exe (`build.bat`, внутри вызывается `pyinstaller --clean ...`).

Хэш пароля генерируется так:

```bat
python -c "import hashlib; print(hashlib.sha256(b'ваш_пароль').hexdigest())"
```

Полученные 64 символа вставляются в `UNLOCK_PASSWORD_HASH`. Сам пароль храните вне
проекта (менеджер паролей или бумажка).

### Защита от отката системных часов

Файл `%LOCALAPPDATA%\FuelVideo\last_seen.dat` хранит последнюю замеченную дату в
формате `YYYY-MM-DD` и обновляется при каждом запуске.

* если текущая дата **меньше** сохранённой — считается, что часы откатили назад;
* в этом случае копирование и сканирование блокируются, в статусе появляется
  «Обнаружен откат системных часов. Копирование заблокировано. Введите код разблокировки.»;
* снять блокировку можно тем же кодом разблокировки.

### Как проверить блокировку

1. Временно поставьте в [`license.py`](license.py) `EXPIRY_DATE = date(2020, 1, 1)`.
2. Запустите `python main.py` — кнопки серые, статус «Срок действия истёк…».
3. Нажмите «Ввести код разблокировки» → введите пароль → кнопки снова активны.
4. Закройте и откройте программу — блокировка вернулась (сессия сброшена).
5. Верните `EXPIRY_DATE = date(2027, 2, 23)`.

Проверка отката часов: после первого запуска откройте
`%LOCALAPPDATA%\FuelVideo\last_seen.dat` блокнотом, поставьте вручную дату из
будущего и запустите программу — должна сработать блокировка отката часов.
